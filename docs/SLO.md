# SLOs

Initial production objectives:

- Runtime availability >= 99.5%.
- Provider observation freshness <= 15 minutes.
- Hardware telemetry freshness <= 2 minutes.
- Evidence persistence success >= 99.9%.
- Unauthorized provider writes = 0.
- Unauthorized financial actions = 0.
- Evidence-loss events = 0.

SLOs do not override fail-closed policy or human approval requirements.
